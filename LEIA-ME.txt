CRAQUE DE BANCO — MODO CARREIRA 2027

Este pacote está preparado como PWA (aplicativo web instalável).

IMPORTANTE: extraia o ZIP e envie TODOS os arquivos desta pasta diretamente para a raiz do seu repositório GitHub Pages, substituindo o index.html antigo quando solicitado. Não envie apenas o ZIP nem coloque os arquivos dentro de uma subpasta.

Arquivos necessários: index.html, manifest.json, sw.js, icon.svg, icon-192.png e icon-512.png.

Depois de salvar (Commit changes), aguarde a publicação do GitHub Pages. Abra o link público no Chrome Android, atualize a página e procure no menu ⋮ por “Instalar app” ou “Adicionar à tela inicial”. Pode ser necessário fechar e reabrir o Chrome.
